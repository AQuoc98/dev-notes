## Two-hour diagnostic

Do this without notes. Record the session if possible.

### JavaScript and TypeScript — 30 minutes

1. Predict and explain an event-loop snippet containing synchronous code,
   promises, `queueMicrotask`, and timers.
2. Implement typed `debounce` or a small event emitter.
3. Model a component's mutually exclusive states without optional-property
   ambiguity.

### React and Next.js — 30 minutes

Explain aloud:

- what causes a React component to render and commit;
- when memoization helps, does nothing, or makes performance worse;
- the boundary between Server and Client Components;
- how rendering and caching choices affect freshness and latency;
- how Suspense and streaming change the user-visible request lifecycle.

### Practical coding — 30 minutes

Build a searchable, keyboard-accessible list from a small local data set. Include
loading, empty, error, and success states plus one useful test.

### System design and behavioral — 30 minutes

- Design an authenticated, high-traffic product listing frontend for 15 minutes.
- Tell one five-minute STAR story about an architectural decision.
- Spend ten minutes reviewing the recording and noting unclear claims,
  unsupported trade-offs, and missing measurements.

## Adjustment rule

Keep every area in the plan, but move one 90-minute block per week toward the
lowest-scoring competency. If English interviewing is a gap, conduct all mock
interviews and project walkthroughs in English instead of creating a separate
grammar curriculum.
