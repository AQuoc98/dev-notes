# Portable templates

Các file trong folder này là adapter mẫu để đưa shared workflow vào host cụ thể. Chúng chưa được bật cho repo cha.

## Suggested usage

1. Review và chỉnh `WORKFLOW-CONTRACT.md`.
2. Copy nội dung phù hợp vào repo/agent target.
3. Giữ skill body và knowledge schema ở shared location.
4. Dùng `AGENTS.md` cho Codex và `CLAUDE.md` cho Claude Code như adapter mỏng.
5. Test discovery, permissions và output trên từng host trước khi commit.
