# Claude Code adapter template

> Template only. Copy/adapt into a target project after review.

Read the shared workflow contract before acting. For each task:

- state the outcome and acceptance criteria;
- keep changes within the declared scope;
- use the smallest tool surface and permission level;
- use a relevant skill for repeatable workflows;
- use subagents only for focused, noisy or parallel work;
- verify actual state with tests, diffs, citations or other evidence;
- report assumptions, risks and unresolved questions;
- never treat memory or generated wiki pages as the only source for mandatory rules.

Do not perform irreversible external actions without explicit approval.
