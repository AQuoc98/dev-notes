# Subtask 09: Define a GTM Folder Organization Strategy

## Objective

Use GTM folders consistently so people can find and review related tags, triggers, and variables without mistaking folders for runtime isolation or access control.

## Scope — Included Items

- Folder taxonomy, naming, ownership, and lifecycle.
- Placement of scoped tags, triggers, and user-defined variables.
- Handling shared components and temporary project folders.

## Deliverables / Outputs

- One GTM folder organization guideline containing the primary taxonomy, naming rules, shared/unfiled/temporary-item handling, ownership, review cadence, cleanup rules, and clarification that folders do not control runtime or access.
- One before/after scoped folder inventory mapping each POC tag, trigger, and user-defined variable to its intended folder, including shared consumers, owner, and cleanup date where applicable.
- One folder-reorganization verification record confirming the reviewed change set and unchanged Preview behavior.

## Dependencies

- Scoped tag, trigger, and variable inventories.
- GTM workspace access.
